Privacy policy

Last updated: 13 November 2026

What Arbitrage accesses

Arbitrage asks for one Google permission: youtube.upload, which lets it upload videos to the YouTube channel you sign in with. It does not read your email, contacts, files, watch history or any other data.

How it is used

The permission is used only to upload videos that the channel owner has prepared to that owner's own channel.

Storage

The sign-in token Google returns is stored only on the owner's own computer. It is not sent to any server other than Google's, and it is never sold, shared or used for advertising.

Google API Services User Data Policy

Arbitrage's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can remove Arbitrage's access at any time at myaccount.google.com/permissions. Removing it makes the stored token useless.
